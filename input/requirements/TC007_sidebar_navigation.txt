TEST CASE: TC-007 — Sidebar Menu Navigation
==============================================================================
Application  : SauceDemo E-Commerce Platform
URL          : https://www.saucedemo.com
Priority     : MEDIUM
Module       : Navigation
Preconditions: User is logged in as standard_user

OBJECTIVE:

all menu items and the logout functionality.

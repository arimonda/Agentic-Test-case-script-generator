==============================================================================
TEST CASE: TC-004 — Shopping Cart Management
==============================================================================
Application  : SauceDemo E-Commerce Platform
URL          : https://www.saucedemo.com
Priority     : HIGH
Module       : Shopping Cart
Preconditions: User is logged in as standard_user

OBJECTIVE:
Verify the full shopping cart lifecycle — adding items, viewing cart,
removing items, and verifying cart badge count accuracy.

==============================================================================
SCENARIO 4A: Add Single Item to Cart
==============================================================================
TEST DATA:
  Login: standard_user / secret_sauce

STEPS:
Step | Action                                    | Input Data              | Expected Result
  1  | Navigate to https://www.saucedemo.com     | https://www.saucedemo.com | Login page loads
  2  | Enter username                            | standard_user           | Username entered
  3  | Enter password                            | secret_sauce            | Password entered
  4  | Click Login                               |                         | Products page loads
  5  | Click "Add to cart" on Sauce Labs Backpack |                        | Button text changes to "Remove"
  6  | Verify the cart badge shows "1"           |                         | Cart icon badge displays "1"
  7  | Click the cart icon in the header         |                         | Cart page opens showing 1 item
  8  | Verify "Sauce Labs Backpack" is in cart   |                         | Item name, description, and price ($29.99) are visible
  9  | Verify item quantity is 1                 |                         | Quantity shows "1"
 10  | Take a screenshot of the cart             |                         | Screenshot captured

1. APPLICATION OVERVIEW
==============================================================================

SauceDemo is a fictional e-commerce web application built to practice
automated testing. It simulates an online store where users can:
  - Log in with different test user accounts
  - Browse a product catalog
  - Sort products by name or price
  - Add/remove items from a shopping cart
  - Complete a checkout flow
  - Log out via a sidebar navigation menu

The application is a single-page React application with multiple "pages"
rendered via client-side routing.

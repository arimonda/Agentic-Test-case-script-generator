==============================================================================
USER ACCOUNTS
==============================================================================

All accounts use the shared password: secret_sauce

Account: standard_user
  - Type: Normal user
  - Access: Full
  - Behavior: Everything works as expected
  - Best for: Happy path testing, full E2E flows

Account: locked_out_user
  - Type: Locked account
  - Access: None (blocked at login)
  - Behavior: Shows error "Sorry, this user has been locked out."
  - Best for: Negative login testing

Account: problem_user
  - Type: Buggy user
  - Access: Full (but with issues)
  - Behavior:
    * Product images are wrong (all show dog image)
    * "Add to cart" may not work on all items
    * Sorting may not function correctly
    * Checkout form may have input issues
  - Best for: Bug detection testing, visual regression

Account: performance_glitch_user
  - Type: Slow user
  - Access: Full (but delayed)
  - Behavior:
    * Login takes ~3-5 seconds
    * Page transitions are delayed
    * Add to cart has delays
    * All functionality eventually works
  - Best for: Timeout handling, performance testing

Account: error_user
  - Type: Error-prone user
  - Access: Full (but unstable)
  - Behavior:
    * Random JavaScript errors occur
    * Some operations may fail intermittently
    * Cart operations may throw errors
  - Best for: Error handling testing, resilience testing

Account: visual_user
  - Type: Visual bug user
  - Access: Full
  - Behavior:
    * Visual inconsistencies in the UI
    * Misaligned elements
    * Different fonts/colors on some items
  - Best for: Visual regression testing
